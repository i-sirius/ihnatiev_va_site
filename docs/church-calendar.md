# Календар у розділі «Священнослужіння»

Календар розміщено на `activity3.html#church-calendar`. Перемикач має два режими:

- Спрощений: вибраний день, піст та найближчі основні свята й початки постів.
- Повний: місяць, вибір дня, повний перелік пам’ятей святих із джерела, пісні вказівки, глас та посилання на біблійні читання.

Основна дата — цивільна григоріанська, у дужках — юліанська (старий стиль). Різдво: 7 січня (25 грудня ст. ст.). Сьогодні визначається за часом Києва. Обраний режим зберігається в браузері. Щоденні тексти джерела українською, інтерфейс і короткий перелік свят — українською й англійською.

## Джерела

Щоденні фактичні відомості: [Благовіст](https://blagovist.info/calendar/), відкритий сервіс `https://blagovist.info/calendar/jsCalData.php?dofcet=YYYY-M-D`. Цей сервіс використовує [офіційний сайт Рівненської єпархії УПЦ](https://rivne.church.ua/sviati-dnia/). Це не власний API центрального сайту УПЦ; походження явно зазначене у блоці календаря.

Сторінка джерела пропонує підключення календаря до інших сайтів. Тут збережено лише фактичні календарні відомості та посилання: без житій, проповідей, перекладів молитов, ікон, відео чи стороннього JavaScript. Розмітка джерела перетворюється на текст, який виводиться через textContent.

Пасхалія і перехідні великі свята розраховуються за юліанським календарем; дати 2026–2030 звірено з [таблицею пасхального циклу OCA](https://www.oca.org/fs/paschal-cycle). Нерухомі свята — за юліанським календарем, а не новоюліанським. Повний перелік пам’ятей святих береться зі щоденних даних джерела, не з календаря OCA.

## Оновлення

У репозиторії збережено повні 2026 і 2027 роки. Календар не робить зовнішніх запитів під час перегляду. За межами доступного періоду він повідомляє про відсутність щоденних даних; дати не підміняються іншим роком.

Оновити дані або додати наступний рік (Python 3, без зовнішніх пакетів):

```powershell
python scripts/sync-church-calendar.py 2026 2027
npm run check:content
```

Скрипт перевіряє дату відповіді для кожного дня, пише рік лише після успішного завантаження всіх днів і оновлює `files/content/church-calendar/index.json`. Для нового року також додайте його JSON до APP_SHELL у `sw.js`, щоб забезпечити доступ без мережі. Зміни потрібно опублікувати звичайним способом. Перед завершенням 2027 року слід додати дані 2028 року.

`npm run check:calendar` перевіряє повноту даних, Різдво, Пасху, перехідні свята, зміну року й перетворення юліанських дат.
