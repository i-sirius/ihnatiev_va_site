# Інструкція редактора Decap CMS

Ця інструкція описує базову роботу з адмін-панеллю сайту `https://iva.net.ua/admin/`.

## Вхід

1. Відкрийте `https://iva.net.ua/admin/`.
2. Натисніть вхід через GitHub.
3. Після входу відкриється список розділів для редагування.

Якщо сторінка входу не відкривається або GitHub не повертає в адмінку, не змінюйте налаштування OAuth самостійно. Це службова частина сайту.

## Draft і Publish

Draft - це чернетка зміни. Вона ще не опублікована на сайті.

Publish - це публікація. Після публікації Decap створює зміну в GitHub, сайт проходить автоматичну перевірку і оновлюється після деплою.

Після Publish зачекайте завершення GitHub Actions і перевірте сторінку на сайті.

## Файли та зображення

У file/image полях Decap може показувати англійські кнопки:

- `Choose different file` - обрати інший файл або замінити поточний.
- `Replace with URL` - вставити посилання замість завантаження файла. Для основних file/image полів сайту цю кнопку вимкнено, щоб матеріали лишались локальними файлами репозиторію.
- `Remove file` - прибрати файл із цього запису.

Для фото бажано заповнювати alt-текст: коротко описати, що зображено на фото.

Для PDF/документів перевіряйте, що назва українською заповнена. English-назву можна залишити порожньою там, де поле позначене як необов'язкове.

## Файл до наукової праці

У колекції `Наукові праці` кожен запис може мати необов'язкове поле `Файл праці`.

1. Відкрийте потрібну працю у списку.
2. У полі `Файл праці` оберіть локальний файл.
3. Використовуйте тільки PDF, DOC або DOCX.
4. Залиште поле порожнім, якщо файла для цієї праці немає.
5. Після збереження на сайті біля цієї праці з'явиться кнопка `Завантажити файл`.

Файли наукових праць зберігаються в папці `/files/publications/`. Не вставляйте шлях вручну і не завантажуйте файл, якщо немає дозволу публікувати його на сайті.

## Чому частина кнопок Decap англійською

Decap CMS підтримує локалі інтерфейсу, але повна локалізація не вмикається лише через `config.yml`: для неанглійських мов потрібна окрема зареєстрована locale-збірка в коді адмінки.

У цьому сайті core-кнопки Decap не перекладаються хаком, щоб не зламати адмінку після оновлень. Замість цього біля file/image полів додано українські підказки, а вставлення URL для локальних файлів вимкнено штатною опцією `choose_url: false`.

## Що краще не міняти без потреби

- `id` у профільних посиланнях. Від нього залежить іконка.
- Службові поля на кшталт `mode`, якщо поруч є підказка.
- Шляхи до файлів вручну. Краще обирати файл через медіатеку.
- Довгі технічні або HTML-подібні фрагменти, якщо вони не винесені в окрему зрозумілу CMS-колекцію.

## Перевірка після публікації

1. Відкрийте сторінку сайту, яку редагували.
2. Оновіть сторінку в браузері.
3. Якщо зміни не видно одразу, зачекайте кілька хвилин і оновіть ще раз.
4. Перевірте українську й англійську версії, якщо редагували обидві мови.

Якщо після публікації сайт виглядає неочікувано, зафіксуйте назву колекції, що редагувалась, і час публікації.
